# ADR-0010 — Articulated Giant Dave by default; magical morph only for world changes

**Date:** 22 October 2026  
**Status:** Accepted

## Context

DH-06B explored moving a painted Dave by (a) optical-flow interpolation between transparent whole-body poses and (b) a browser study rotating separately composited arm parts around shoulder and elbow joints. Optical-flow movement produced morphing faces, arms and clothing; the jointed approach felt more like a real character, but revealed missing painted underarm/torso details. The owner chose **proper articulated motion**, while retaining the creative possibility of morphing for **major magical transitions**.

## Decision

- **Character acting (default):** Rigged/layered, anatomical joint-driven and limited mesh deformation. Use for idle, blink, small looks, head turns, reaching, pointing, presenting and return to idle.
- **Scene magic (exception):** Morphing/dissolving/transformation can be proposed for significant intentional events, such as entering a destination, changing world or dramatic appearance/departure. It must be clearly staged as magic, visually reviewed and never used to disguise faulty everyday movement.
- **No more brute-force frame generation for ordinary movement.** Draw overlapping, clean transparent paint layers and build an editable rig. The existing seven-frame/optical-flow studies are experiments, not a production motion format.
- **Start small:** Production idle + blink + one clean welcome reach + return, then point/present. Rive is a candidate; test it against a smaller Canvas approach before selecting the runtime.
- **Keep owner control:** no hidden compulsory introduction, no click-intercepting character layer, static/reduced-motion fallback and explicit approval before merging new animation to the homepage.

## Consequences

The asset production burden moves to coherent, independently painted body, shoulder, arm, face, hand and overlap layers. A missing or poorly painted joint cannot be solved by easing a full-image crossfade. Preserve the four approved key-pose illustrations as the character identity baseline. Commit the complete **[DH-06C1 production layered rig specification](../GIANT_DAVE_LAYERED_RIG_SPEC.md)** as the build contract; drawing assets and production runtime remain separate implementation/review gates.

This decision does not authorise automatic publication of newly generated assets, and does not merge any prior draft motion experiment.
