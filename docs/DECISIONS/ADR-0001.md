# ADR-0001 — Original private-first repository proposal

- **Date:** 20 October 2026
- **Status:** Superseded by ADR-0002

## Original proposal

Keep the DaveHub source repository private, with a separately hosted public website. This would allow unfinished discussions and project metadata to remain hidden until approved.

## Outcome

The GitHub remote was created as **Public** by the repository owner. Rather than silently changing the chosen visibility, the project follows ADR-0002. The original reasoning remains useful: internal, personal and third-party content must still be protected.
