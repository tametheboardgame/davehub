# ADR-0002 — Public planning repository with publication controls

- **Date:** 20 October 2026
- **Status:** Accepted for current repository configuration

## Context

The repository `tametheboardgame/davehub` was created by its owner with Public visibility. The project is intended to become a public creative destination, but other connected projects and development materials may be private.

## Decision

Keep the existing repository visibility unchanged. Restrict committed content to deliberately public-safe source, fixtures and documentation. Require explicit review before any linked project, likeness, recording, internal work or third-party asset is exposed through DaveHub.

## Consequences

- GitHub history, even before a public website launches, must be treated as published information.
- Experimental prototypes use placeholders until material is cleared.
- External integrations remain read-only and publication is human-approved.
- Private work and sensitive notes must never be copied into this repository.
- Repository visibility can be revisited by the owner independently of the site's eventual visibility.
