# ADR-0006 — Intentionally primitive "boring menu" mode

**Date:** 21 October 2026  
**Status:** Accepted

## Decision

The immersive homepage must prominently offer the exact link:

> I want to view this as a menu coz I'm boring

Selecting it switches to an **actually primitive, deliberately 1990s-looking, basic HTML website**. The humour is the absurd contrast with the art-directed immersive site, rather than an animated gag or a contemporary clean 'list view'.

Use straightforward document flow, default-looking headings, Times New Roman or serif text, blue underlined links, horizontal rules and nearly absent decoration. It should be accessible and performant, not an inaccessible 1990s parody.

Both modes show **the same public project catalogue** and support meaningful links, navigation, stable project URLs and switching back to immersive mode.

## Consequences

A simple plain-HTML rendering path is a first-class product requirement, not a fallback afterthought. The main interactive world can be ambitious without locking visitors into it.
