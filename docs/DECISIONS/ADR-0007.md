# ADR-0007 - DaveHub primary logo approved

Date: 21 October 2026
Status: Accepted

The approved DaveHub wordmark is the transparent, 2172 x 724 PNG at `assets/branding/davehub-logo-approved.png`.

Composition: silver-blue 'Dave', gold-to-purple-blue cosmic 'Hub', gold and blue orbital ring, two small gold planets and a four-point star.

SHA-256 of the exact approved PNG: `ac0c0d298c58e19d0a3f47972b8f4d828c8fc64231b6177aed5c3878858d4033`.

Google Drive backup: https://drive.google.com/file/d/1TcM_93rvTBbPxNECHHRs17z7ugiGBG9A/view

The PNG is the visual source of truth. Do not regenerate or overwrite it. A pixel-perfect SVG wrapper can embed the PNG, but this is not a true vector conversion. Any all-vector recreation must be reviewed before replacing the approved artwork.

Use this approved PNG on the Concept 1 floating-islands homepage until a faithful production-ready vector version is separately approved. This is visual approval, not legal trade mark clearance.

## Accepted SVG and rejected draft

The exact-fidelity SVG wrapper at [`assets/branding/davehub-logo-faithful.svg`](../../assets/branding/davehub-logo-faithful.svg) is accepted for website use. It embeds the approved raster PNG, so it is not a true-vector reconstruction. The automatic vector-draft version has been rejected because it visibly distorts the wordmark and orbital details; it must not appear in downloads or the repository. There is no outstanding requirement to pursue a pure-vector reproduction unless specifically requested.
